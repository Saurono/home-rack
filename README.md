# 家用机架 · Home Rack

用于集中安置家庭网络设备、服务器、ITX 电脑、微型 NAS 与 UPS 的铝型材机架设计项目。

当前设计基线为 **v0.1.0**，处于需求整理与概念设计阶段。设备型号、尺寸、载荷与性能目标尚未冻结。

## 文档入口

- [家用机架设计手册与指南](家用机架设计手册与指南.md)：需求追踪、四个功能区及结构、散热、防尘、NVH、维护与扩展要求。
- [设备与设计参数表](设备与设计参数表.md)：需要补齐的设备和场地参数。
- [版本日志](版本日志.md)：设计基线、变更及验证状态。
- [云端接续指南](云端接续指南.md)：云端环境配置建议与项目交接上下文。

## 当前工作重点

优先补齐服务器、ITX 机箱、四盘位硬盘箱和 UPS 的型号、尺寸、重量、功耗，以及场地宽深高上限，再推导层高与总体尺寸。

项目文档使用 UTF-8 编码。当前仅有 Markdown 文档，无依赖安装、应用启动或自动化测试要求。修改设计时，应同步检查需求追踪、参数表及版本日志的一致性。
